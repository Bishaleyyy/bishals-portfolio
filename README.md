## About the Project

Welcome to my personal portfolio repository!

This website represents my journey as a **BSc. CSIT student**, aspiring frontend developer, and video editor from Nepal.

The portfolio is designed to present my background, technical skills, selected projects, and creative interests through a clean and modern web experience.


## Features

- Modern and professional dark-themed design
- Responsive layout for different screen sizes
- Interactive user interface and animations
- Personal introduction and profile section
- Skills and technologies showcase
- Selected projects with relevant links
- Contact and social media links
- Interactive profile image hover effect

## Getting Started

To run this project locally:

**1. Clone the repository**

```bash
git clone https://github.com/Bishaleyyy/bishals-portfolio.git
```

**2. Open the project folder**

```bash
cd bishals-portfolio
```

**3. Run the website**

Open `index.html` in your browser.

You can also open the folder in Visual Studio Code and use the Live Server extension.
